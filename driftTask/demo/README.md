# Demo Browser

This is a **visual demo browser**, not the real experiment.

## Usage

Open `demo/index.html` in a web browser. Use the button controls to preview different screens:

- **Version**: Simple (no bar) or Rich (blue progress bar)
- **Block**: No-Boundary or Boundary
- **Screen**: Encoding, Single Placement, Paired Placement, Recognition
- **Encoding Phase**: Item Only or Item + Value

Screens are representative mockups using placeholder stimuli. No timing is enforced, no data is collected.

## Editing defaults

- Change the mock item/value in `demo.js` (`mockFilename`, `mockValue`, `mockTrialIndex`)
- Change visual parameters in `js/config.js`
